# playing-with-git

El propósito de este repositorio es brindar herramientas que te permitan aprender los conceptos básicos y avanzados de git y gitlab para finalmente optar por una certificación en gitlab foundations. 

El contenido está diseñado para mostrar paso a paso el funcionamiento de git. Mucho del contenido es extraido con traducido desde las siguientes fuentes:

| Fuente |
|---|
| https://learn.microsoft.com/en-us/training/paths/github-foundations/  |

Se ha utilizado además Chat GPT en la traducción de los contenidos.
