## Bienvenido al módulo de Introducción a Git

En este módulo comenzarás a construir una base sólida en **control de versiones** utilizando Git, el estándar de la industria para gestionar cambios en proyectos de software y documentación. Aquí no solo aprenderás comandos, sino que entenderás el modelo conceptual detrás de Git: cómo se registran los cambios, cómo se estructura el historial y cómo trabajar de forma segura en entornos colaborativos. El objetivo es que desarrolles criterio técnico y dominio práctico desde el inicio.

---

## Antes de comenzar: instala Git

Para poder realizar los ejercicios necesitas tener Git instalado en tu sistema.

### 🔹 Windows

Descarga el instalador oficial desde:

https://git-scm.com/download/win

El instalador incluye:
- Git Bash (terminal con entorno tipo Unix)
- Integración opcional con PowerShell y CMD
- Herramientas gráficas básicas

Durante la instalación, si eres principiante, puedes dejar las opciones por defecto.

---

### 🔹 macOS

Descarga Git desde:

https://git-scm.com/download/mac

También puedes instalarlo usando Homebrew:

```bash
brew install git
```

### 🔹 Linux

Instálalo desde el gestor de paquetes de tu distribución.

Debian / Ubuntu:

```bash
sudo apt update
sudo apt install git
````
Fedora:

```bash
sudo dnf install git
```

Arch Linux:

```bash
sudo pacman -S git
```

## Luego verifica la instalación:

Abre una terminal y ejecuta

```bash
git --version
```

Si Git está correctamente instalado, verás la versión instalada en tu sistema.
